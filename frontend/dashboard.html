نتیجه تشخیص

درباره سامانه BHAM

سامانه هوشمند مدیریت آلارم و پایش سلامت لایه‌های حفاظتی ایمنی فرآیند (BHAM) راهکاری مبتنی بر هوش مصنوعی برای مجتمع پتروشیمی غدیر است که توسط شرکت پتروپالاتوس توسعه می‌یابد. این سامانه چهار ماژول تخصصی دارد:

  • ماژول ۱ — تحلیل آلارم: DBSCAN + Isolation Forest برای شناسایی چترینگ، طوفان آلارم و علت‌های مشترک.
  • ماژول ۲ — پایش لایه‌های حفاظتی: محاسبه شاخص سلامت BPCS/SIS/ESD/Relief/Procedural و تشخیص تجمع ضعف.
  • ماژول ۳ — پیش‌بینی توالی: Random Forest + زنجیره مارکوف برای پیش‌بینی توقف اضطراری پیش از وقوع.
  • ماژول ۴ — ریسک پویا: XGBoost + Weibull AFT برای برآورد ریسک و بهینه‌سازی برنامه تست.
  • ماژول ۵ — تشخیص خطای TEP: PCA + Random Forest روی بنچ‌مارک استاندارد صنعت.
